# Medicenter

Sistema de gerenciamento da clínica médica Medicenter (Java + Spring Boot + MySQL).

## Equipe
- João
- Mateus

## Como rodar
1. Criar o banco `medicenter_db` no MySQL
2. Configurar usuário e senha em `application.properties`
3. Rodar `MedicenterApplication`

## Fluxo de branches
- `main`: versão estável
- `develop`: integração
- `feature/*`: uma por tarefa
